# 浏览器侧边栏与页面级草稿

本记录由实现者根据代码、自测和真实 Chrome 操作整理，不代表独立 reviewer 审查。

## 行为

- 工具栏收录改为全窗口侧边栏；点击网页与跨标签复制不会关闭表单，正在编辑的岗位固定到原始来源。
- 草稿保存在 `chrome.storage.session`，包含来源标签 ID、文档 ID、URL 与独立草稿 ID。关闭侧边栏、Service Worker 重启可恢复；来源刷新、导航、标签关闭时清理；浏览器重启不恢复。
- 刷新同一 URL 也会产生新文档 ID。旧编辑消息、旧 AI 请求、迟到结果均需匹配草稿/任务及文档身份，否则丢弃。
- App 增加异步解析任务的启动、查询和取消接口，均要求原有 Token。任务限时 90 秒、缓存 10 分钟、有容量上限，结果仅在内存中；取消后不保留页面内容。
- 取消可先于启动请求抵达，后端保留不含页面数据的取消标记，避免请求乱序重新启动任务。
- AI 仅填充没有被用户修改的字段，包括保护用户明确清空的字段。成功收录清空草稿，失败可重试。
- 保留原同步解析接口和右键快速收录，兼容旧扩展；本轮 App 和扩展构建版本为 0.1.2。

## 已验证

- 前端 42 项测试通过，其中 8 项扩展测试覆盖面板关闭恢复、同 URL 刷新、SPA 跳转、旧输入/结果丢弃、手动字段保护、重复点击 AI 和成功/失败收录。
- Rust workspace 81 项测试通过；新增真实本地模拟模型服务测试证明 HTTP 启动响应结束后任务仍独立完成，可由后续请求读取。鉴权和先取消后启动均有测试。
- 扩展新增独立 TypeScript 检查并接入 CI，生产构建及 ZIP 检查通过。
- 在用户实际 Chrome 中重新加载本项目目录的扩展，已确认版本 0.1.2 和侧边栏入口。
- 虚构页面上实测：点击页面、复制文字到城市字段，面板不关闭；关闭再打开，手动公司和城市仍保留；跨标签复制到部门字段时来源岗位未切换；刷新来源同网址后草稿为空，没有恢复旧内容。
- SPA 跳转同样已在真实 Chrome 验证清空。验收草稿、临时浏览器标签和本地测试服务已清理；用户的投递记录及设置与更新前备份逐行比较无变化。
- 用户完成 macOS 钥匙串授权后，真实模型请求验收通过：返回清洗后的 JD，解析前和解析中手动修改的公司/城市字段均保留。
- 在真实任务显示“AI 解析中”时关闭侧边栏，确认面板已关闭；重新打开后成功读取后台完成的结果，仍保留手动编辑。
- 再次启动解析并立即刷新来源同网址，草稿即时清空；重新打开仍为空，旧结果没有重新填回。
- 钥匙串授权由用户在系统窗口完成，未通过工具读取或输出密钥内容。
