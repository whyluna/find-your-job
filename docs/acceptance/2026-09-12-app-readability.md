# App 阅读层次优化验收

## 范围

- 移除按 `rounded-xl + border` 无差别覆盖背景的全局规则，改用显式的内容面板、表头、阅读区和状态分组样式。
- 看板：淡色阶段背景、统一状态颜色、响应式卡片网格；公司和岗位最多两行，部门独立显示，补充地点，弱化重复批次标签。
- 投递表格：交替行背景、悬停/键盘焦点反馈；公司与部门同列，扩大岗位阅读空间；地点不拆行，完整内容保留在悬停提示及详情中。
- 公司库和 offer 对比采用同一表格样式。面经与面试详情区分题目、我的回答和理想回答；JD 改为适合正文阅读的字体与底色。
- 仪表盘、统计、日历、简历库、设置页同步使用分组表头、分层操作区或交替列表；提高深浅色辅助文字对比度。
- 保留固定页眉、已有字号、投递状态规则及跨行拖动确认。空行与非空行共用顶部拖入反馈。

## 隔离界面检查

`scripts/check-ui-readability.cjs` 对本地生产前端预览注入模拟 IPC，使用全新浏览器上下文，**不连接 App HTTP 服务、数据库或用户浏览器配置**。运行需要外部提供 Playwright，不改变项目运行时依赖。

检查内容：24 个模拟岗位、多阶段状态、长公司/部门/职位、6 道含公式的面经、3 份模拟简历；1280×900 深浅色与 960×640 看板。检查了各主页面加载无运行时错误、页面不横向溢出、表格交替色、地点不换行、页眉滚动固定、有效/无效及空状态拖入提示、Escape 取消后提示清除且没有排序写入。

截图仅含合成数据，输出在临时目录，不提交真实求职信息。隔离测试不等于 macOS 原生窗口或真实业务写入验收。
