## 过程中发现并修复的真实缺陷

1. 看板卡片/表格行/面试卡头为纯 div（AX 不可按/VoiceOver 不可达）→ role=button+键盘支持
2. 面试卡快捷操作被包进可展开头部语义 → AX 误触删除（顺带验证删除回退）→ 结构分离
3. deadlineLabel 用小时 ceil 导致跨日语义错误 → 日历日差
4. 面经搜索 SQL 拼接注入风险 → 参数绑定
5. 时间戳格式不统一致字符串比较失效 → 全库 RFC3339 微秒定长

## 已知限制（记录在案）

- WKWebView 的 AX 树在 SPA 路由切换后可能滞后（自动化观察受限，不影响用户操作）
- 拖拽看板改状态依赖指针事件，键盘替代路径为详情页"添加事件"表单
- IMAP 自动同步未实现（.eml 导入+审核闭环已交付；自动拉取留后续版本）
- 剪藏走 HTTP 通道后，应用内列表需切页/刷新才可见（React Query 重新挂载即同步）
