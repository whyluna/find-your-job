## 过程中发现并修复的产品缺陷

1. **卡片/表格行/面试卡头是纯 div**：AX 无法按下（对 VoiceOver 用户同样不友好）→ 全部加 role=button + tabIndex + Enter 键支持。
2. **面试卡快捷操作被包进可展开头部的语义里**：AX 误触"删除面试"导致面试被删（顺带验证了删除回退链路）→ 展开区与操作区结构分离。

## dev 二进制的自动化限制（切换打包版验收的原因）

- 无 bundle id → computer-use 的键盘路由（type/key）、坐标点击、窗口像素捕获全部被拒
- AXSetValue 写入不触发 React onChange → 文本输入需走"聚焦 + System Events 剪贴板粘贴"通道
- 打包版（com.findyourjob）具备完整 bundle 身份，AX/键盘/坐标/截图全链路可用
