# 公司关注与招聘季跟进（0.1.3）

本记录由实现者根据代码、自测和界面操作整理，不代表独立 reviewer 审查。以下记录为 v0.1.3 的发布前验收依据。

## 实现范围

- 公司可以独立关注，无需创建占位岗位。官网/招聘网站属于公司资料，本届专题链接、状态、目标方向、城市及备注属于招聘季。
- `company_watch` 按公司、毕业届次、招聘季唯一；`company_watch_check` 保存查看及操作历史。状态为待确认、尚未开启、招聘已启动、已结束，暂停关注单独记录。
- 打开网站不更新查看时间。记录结果才更新上次查看，并按周期安排下一次；“7 天后再看”只调整安排，不伪造查看记录。暂停、结束停止提醒，恢复后按原周期安排。
- 支持每 3 天、每周、每两周、自定义周期和单次提醒。仪表盘显示待查看公司，日历显示查看日期并可定位相应招聘季。
- 系统通知沿用用户主动开启的权限设置，App 运行时检查；按到期时间去重，每个本地自然日至多发送一条公司汇总通知。
- 插件提供岗位/公司两套表单。公司模式无需岗位名称，可提取公司名称、官网与招聘网站建议并手动确认，不自动判断招聘启动。
- 两套草稿互不覆盖；关闭重开保留，来源刷新/导航/关闭清空，浏览器重启不恢复。失败保留输入；提交前等待并重试尚未保存的编辑，避免发送旧字段。
- 公司按完整名称或唯一别名复用；有歧义时要求明确选择，不以共享招聘域名合并。后续意向岗位复用公司 ID，可从公司卡片进入精确的关联岗位筛选。
- 新 JSON 备份 v3 包含公司关注和查看历史，兼容旧 v1/v2 导入；旧 App 不支持 v3 备份。

## 界面验收与边界

使用电脑操控在 `scripts/qa/company-watch.html` 和 `scripts/qa/extension-company.html` 中完成隔离预览。页面明确标注示例数据，只使用内存模拟 IPC / 浏览器接口，不连接真实 App 数据库。

- App 界面：新增关注、状态和日期显示、记录结果、暂停/恢复、预填并添加意向岗位、关联岗位筛选、进入岗位详情、日历查看与招聘季定位均走通。
- 插件界面：手动改公司名/届次/状态，关闭重开仍保留；模拟保存失败后输入仍在，重试成功只保存公司关注并清空草稿；刷新同一来源文档后再打开仍为空。
- 检查了浅色、深色，以及实际 960×640 浏览器视口，公司列表未横向溢出。表单可正常滚动到操作按钮。
- 隔离界面用于验证展示与前端交互，不声称它等同真实 Chrome 扩展端到端测试；实际存储、鉴权和业务语义由 Rust 接口测试验证。真实浏览器插件未强制重载，以免清掉用户正在编辑的草稿。

## 本机安装与数据安全

- 安装前使用 SQLite 一致性备份保存本地数据库，备份只留在本机临时私有目录，不进入 Git。
- `pnpm app:install` 构建并替换 `/Applications/FindYourJob.app`，安装版本 0.1.3，签名检查通过，构建目录中的重复 App 副本已清理。
- 启动后数据库完整性检查为 `ok`；与安装前备份逐表比较，15 个原有表（含迁移元数据）内容均未变。新增关注/查看历史表为空，未写入测试公司或测试岗位。
- 在真实安装版确认了关注入口、空状态、表单字段及取消行为；已退出空表单，供用户自行验收。
- 插件输出位于 `apps/extension/build/chrome-mv3`，ZIP 为 `apps/extension/build/fyj-extension-0.1.3-chrome.zip`。从源码目录加载的扩展需要重新加载；从 ZIP 解压安装的扩展需要替换为新版文件后重新加载。

复现隔离界面：`pnpm exec vite --host 127.0.0.1 --port 5181`，打开上述两个 HTML 路径。App 预览使用 HashRouter 保持隔离入口在热刷新时有效；所有示例数据随页面重新加载清空。
