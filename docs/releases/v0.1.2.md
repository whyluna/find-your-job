# FindYourJob v0.1.2

把感兴趣的岗位先收好，准备好后再投递。本版完善意向岗位工作流，并优化浏览器收录和 App 的密集信息阅读体验。

## 主要更新

- **意向岗位 → 正式投递**：收藏招聘链接与 JD，记录计划投递时间和网申截止时间，准备好后确认实际投递日期、渠道和简历。意向岗位不混入正式投递统计。
- **浏览器侧边栏收录**：可以一边看网页、一边补充岗位资料，点击网页或切换标签页不会关闭表单。关闭再打开侧边栏可继续编辑当前草稿。
- **刷新来源页面自动清理**：刷新、跳转岗位或关闭来源标签会清空草稿；浏览器重启不恢复。已经保存到 App 的岗位不受影响。
- **后台 AI 解析**：关闭侧边栏后仍可完成解析，再打开可读取结果；刷新来源会取消旧任务，迟到结果不会重新填入，AI 不覆盖手动编辑过的字段。
- **更清晰的 App 界面**：看板按阶段使用淡色分组，表格增加交替行底色并调整列宽；公司、面经、简历库、日历等页面统一信息层次，兼容深浅色和窄窗口。
- **减少拖拽冲突**：投递页的普通文字不可划词，搜索和编辑框仍能选字；空行与非空行采用一致的顶部拖入反馈。
- **CSV 流程恢复与链接去重**：新版 CSV 可恢复事件、面试、题目及投递计划；保留岗位 URL 中有业务意义的路径、参数和尾斜杠，避免误合并不同岗位。

## 下载与升级

- `FindYourJob_0.1.2_aarch64.dmg`：Apple Silicon，macOS 12 或更高版本。
- `FindYourJob-browser-extension-v0.1.2.zip`：Chrome / Edge 116 或更高版本，Manifest V3 侧边栏扩展。
- `SHA256SUMS.txt`：两个安装包的 SHA-256 校验值。

建议先在旧 App 的“设置 → 数据 → 导出全部数据”保存备份，再用 DMG 替换“应用程序”里的 App。正常升级沿用现有本地数据。

**请同步升级 App 和扩展。** 新版扩展的后台 AI 解析需要 App v0.1.2；新版 App 仍兼容旧扩展的同步解析接口。扩展 ZIP 解压后，在浏览器扩展管理页重新加载原目录，或通过“加载已解压的扩展程序”加载新目录；按需在扩展“设置”中填写 App 接入 Token。

在招聘网页点击扩展图标打开侧边栏，点击“收录当前页面”，按需 AI 解析或手动补充，然后“添加到意向岗位”。完整联动说明见 [README](https://github.com/whyluna/find-your-job/blob/v0.1.2/README.md#浏览器扩展)。

## 已知限制

- 本次 DMG 使用 ad-hoc 本地签名，**尚未经过 Apple 公证**，不能视为 Developer ID 公证版。
- 本次仅提供 Apple Silicon 安装包，不提供 Intel DMG。
- 页面草稿只属于当前来源页面，不用于跨刷新或跨浏览器重启保存资料；需要长期保留的岗位请添加到 App。

## 验证

前端与扩展类型检查、42 项前端/扩展测试、Rust 格式检查、Clippy 和 81 项 Rust 测试通过。另有 1 项真实数据库探针按设计跳过，常规测试不访问用户数据库。界面与侧边栏验收记录见 [docs/acceptance](https://github.com/whyluna/find-your-job/tree/v0.1.2/docs/acceptance)。

依赖审计按仓库策略通过，仍有 7 条间接依赖告警（6 条停止维护告警和 1 条 Linux GTK 依赖 glib 的健全性告警）；本次 Apple Silicon 目标的依赖树不包含 glib。不将审计通过表述为零告警。
