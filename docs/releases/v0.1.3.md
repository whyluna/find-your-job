# FindYourJob v0.1.3

先关注公司，等招聘启动后再收录岗位。本版新增公司关注与招聘季跟进，并打通 App 和浏览器插件。

## 主要更新

- **独立关注公司**：没有具体岗位也能保存公司信息、官网、招聘网站和本届校招专题，不创建占位岗位、不计入投递统计。
- **按招聘季跟进**：分别记录毕业届次、秋招/春招/实习招募和“待确认、尚未开启、招聘已启动、已结束”，新一届不覆盖旧历史。
- **定期查看提醒**：支持单次、每 3 天、每周、每两周或自定义周期；仪表盘与日历显示安排，系统通知按到期记录去重、每天最多合并提醒一次。
- **查看历史与暂停恢复**：打开网站不算已查看；主动记录结果才更新查看时间和下次安排。支持暂停、恢复以及“7 天后再看”。
- **插件新增公司模式**：侧边栏可切换“收录岗位 / 关注公司”，公司模式不要求岗位名称。两套草稿分别保留，关闭重开不丢失，刷新来源页面后清空。
- **更可靠的保存与关联**：提交前等待并重试未保存的编辑；公司按全名或唯一别名复用，不以共享招聘域名合并。招聘启动后可添加意向岗位并查看关联岗位。
- **直接删除关注**：每张卡都显示“删除关注”，无需先暂停。确认后只删除该招聘季的关注和查看历史，公司资料、其他招聘季及已有岗位保留。
- **备份升级**：JSON 备份 v3 纳入公司关注与查看历史，继续支持旧 v1/v2 备份导入。

## 下载与升级

- `FindYourJob_0.1.3_aarch64.dmg`：Apple Silicon，macOS 12 或更高版本。
- `FindYourJob-browser-extension-v0.1.3.zip`：Chrome / Edge 116 或更高版本。
- `SHA256SUMS.txt`：安装包 SHA-256 校验文件。

建议升级前在“设置 → 数据 → 导出全部数据”保存备份，再替换“应用程序”中的 App。正常升级会保留现有公司与投递记录。

**请同步更新 App 和插件。** 扩展 ZIP 解压后，在浏览器扩展管理页重新加载更新后的目录；若改用新的安装目录，按需在扩展“设置”中重新填写 App 接入 Token。完整使用说明见 [README](https://github.com/whyluna/find-your-job/blob/v0.1.3/README.md#关注尚未启动招聘的公司)。

## 使用边界

- 公司提醒是提醒你主动查看，**不会自动抓取网站或判断招聘已启动**。公司名称和网址提取结果需人工核对。
- 系统通知需要主动开启权限并保持 App 运行；退出 App 后不发送提醒。
- 删除关注及其查看历史不可撤销，请在确认框核对公司与招聘季。
- 新版导出的 JSON v3 备份需要 App 0.1.3 或更高版本恢复，旧版 App 不支持此格式。
- 本次 DMG 为 ad-hoc 本地签名，尚未经过 Apple 公证；仅提供 Apple Silicon 安装包。
