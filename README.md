## 适合这些场景

- **同时跟进多家公司**：用看板或表格集中查看当前阶段、批次、渠道、岗位和下一步安排。
- **校招流程节点多**：统一记录测评、笔试、多轮面试、OC、意向书、offer 和签约，不再依赖零散表格。
- **面试后及时复盘**：按公司、岗位和轮次沉淀题目、自己的回答、理想回答、表现与知识点标签。
- **担心错过截止和面试**：在仪表盘查看近期待办，在日历中统一查看投递日、截止日期与面试安排。
- **需要比较多个机会**：用可调权重对薪资、成长、城市、工作生活平衡和稳定性进行横向比较。
- **希望数据留在本机**：核心数据保存在本地 SQLite，可随时导出 JSON 备份或使用 CSV 迁移。

## 功能

### 公司关注

- 没有具体岗位时也可以先关注公司，保存公司官网、招聘网站、本届校招专题、目标方向与城市。
- 按毕业届次与招聘季分别管理“待确认 / 尚未开启 / 招聘已启动 / 已结束”，下一届新建记录，不覆盖历史。
- 记录查看结果会更新“上次查看”和下次安排；打开网站不算已查看，“7 天后再看”也不会伪造查看记录。可以暂停、恢复关注，或选择单次/每周/自定义周期提醒。
- 每张关注卡都直接提供“删除关注”，无需先暂停；确认后仅删除该招聘季的关注与查看历史，公司资料、其他招聘季和已有岗位保留。
- 仪表盘汇总待查看公司，日历显示下一次查看安排；系统通知需在设置中主动开启且 App 保持运行，同一到期记录不重复提醒，每天最多合并通知一次。
- 插件侧边栏支持“收录岗位 / 关注公司”。公司模式无需填写岗位，草稿仍遵循“关闭保留、刷新来源清空、重启浏览器不恢复”的规则；需要 App 和插件 0.1.3 配套使用。
- 招聘启动后，可从公司卡片添加意向岗位或查看关联岗位。关注公司本身不计入投递统计，不会自动创建职位或认定已投递。
- 新 JSON 备份格式 v3 包含公司关注与查看历史，并继续支持旧 v1/v2 备份导入；v3 备份需要新版 App 恢复。

### 投递跟踪

- **意向岗位 → 正式投递**：手动添加或通过浏览器扩展收藏感兴趣的职位，保存原招聘链接、JD、标签和优先级；准备好后从详情打开岗位页面，完成网申，再点击“确认已投递”。
- 确认时填写实际投递日期、渠道、批次和所用简历，原有职位资料与准备记录会保留；已投递的岗位也可直接补录。
- 意向岗位不计入投递量、渠道/批次分布、简历过筛率或沉默投递；可在岗位范围中筛选意向岗位、投递记录和已归档岗位。
- 意向岗位可设置计划投递时间和网申截止时间，在仪表盘和日历查看；开启系统提醒后会按设置的提前量通知，过期未处理仍保留在待办中。正式投递、放弃或归档后停止待投递提醒。
- 看板与表格双视图，支持搜索、状态筛选和拖拽排序。
- 看板使用浅色阶段分组，表格使用交替行底色；长公司名与岗位名支持两行显示。投递页普通文字不可划词，避免与拖拽冲突，输入框仍可正常选字和编辑。
- 跨状态拖拽时提供明确目标反馈；状态变更通过事件确认，避免误操作。
- 状态由时间线事件与面试记录推导，补录、删除或改判后会自动重新计算。
- 支持批次、渠道、Base、部门、优先级、标签、薪资范围和归档。

### 时间线与面试

- 在投递详情中统一添加投递、测评、笔试、HR 沟通、OC、offer、签约等事件。
- 面试按轮次记录时间、形式、地点或链接、时长和结果。
- 每轮可继续记录题目、自己的回答、理想回答、回答质量和知识点标签。
- 面经页按岗位与轮次聚合全部题目，便于复习和检索。

### 日历、统计与决策

- 月历统一展示面试、流程截止日期和投递记录。
- 仪表盘聚合近期截止与面试安排。
- 过期但尚未填写结果的面试会进入“待补结果”，不会从待办中消失。
- 统计页提供历史流程进展、近 8 周投递趋势、渠道/批次分布和按最后流程事件计算的沉默投递。
- offer 对比支持五维加权评分，权重和评分均保存在本机。
- 可选 macOS 系统提醒只在设置页主动开启，并可调整截止日期与面试的提前量。

### 资料与收录

- 保存 JD 快照，避免招聘链接失效后无法回看岗位要求。
- 简历库管理不同岗位方向的文件版本，并可为投递标记实际使用的版本。
- 支持投递附件、公司资料与招聘官网维护。
- 可选浏览器扩展支持从 Boss 直聘、牛客、猎聘、实习僧及带有 JobPosting 数据的招聘页面收录岗位。
- 可选配置 OpenAI 兼容接口，对网页岗位信息进行结构化提取；API Key 只保存在本机，启用后岗位页面内容会发送到你配置的模型服务商。

### 本地数据

- 数据库存放于：
  `~/Library/Application Support/com.findyourjob/findyourjob.db`
- JSON 全量导出与覆盖式恢复会包含数据库记录和受管文件，但不会导出 LLM API Key 或浏览器扩展 Token；恢复后扩展 Token 会更新。
- 支持带预检、中文值映射、重复识别和事务保护的 CSV 导入导出。
- 新版 CSV 的“流程数据”列保存完整事件、面试、题目和自定义事件定义，回导时恢复招聘进度；请保留这一列。普通 CSV 可迁移当前状态和已知轮次，但不会虚构缺失的题目与面试结果，预检会显示恢复范围。简历和附件文件使用 JSON 全量备份迁移。
- 岗位链接去重统一协议和域名的大小写，保留路径、业务参数及尾斜杠的区别，避免误合并不同职位。
- 浏览器扩展仅通过带 Token 的本机 `127.0.0.1` 接口与 App 通信。
- LLM API Key 保存在 macOS 系统凭据库，不写入 SQLite。

## 安装

### 下载 DMG

1. 从 [v0.1.3 Release](https://github.com/whyluna/find-your-job/releases/tag/v0.1.3) 下载 `FindYourJob_0.1.3_aarch64.dmg`。
2. 打开 DMG，将 FindYourJob 拖入“应用程序”。
3. 当前版本为本地签名、尚未经过 Apple 公证；首次启动如被 Gatekeeper 阻止，请在 Finder 中右键 App 并选择“打开”。

当前发布包面向 Apple Silicon、macOS 12 或更高版本。

### 从源码构建

需要 Node.js 22+、pnpm 与 Rust：

```bash
pnpm install
pnpm tauri build
```

标准 `pnpm tauri build` 只构建，不会关闭正在运行的应用，也不会修改 `/Applications`。

项目维护者希望构建后立即替换本机安装版时使用：

```bash
pnpm app:install
```

该命令会：

1. 构建 App 与 DMG；
2. 替换 `/Applications/FindYourJob.app`；
3. 校验安装结果；
4. 删除 `src-tauri/target/release/bundle/macos` 下的 App 副本。

## 浏览器扩展

v0.1.3 扩展采用浏览器侧边栏，需要 Chrome / Edge 116 或更高版本。请同步升级到本次 Release 中的 App 和扩展：公司关注需要 App v0.1.3；新版 App 仍兼容旧扩展的岗位收录与解析接口。

升级 App 前建议在“设置 → 数据 → 导出全部数据”保存 JSON 备份。已安装扩展的用户可用新版文件替换原扩展目录，然后在扩展管理页点击“重新加载”；如使用新的解压目录，则重新加载该目录并按需填写 Token。

### 侧边栏草稿规则

- 点击工具栏图标打开侧边栏，网页与岗位表单可同时操作。切换标签页复制资料时，仍固定编辑原岗位；点击“收录当前页面”才切换来源。
- AI 结果和手动编辑只保存到当前浏览器会话、当前来源页面。关闭再打开侧边栏可继续编辑；**刷新来源页面（即使网址不变）、跳转岗位或关闭来源标签，会自动清空草稿**。浏览器重启不恢复。
- AI 请求由 App 后台托管，关闭侧边栏后仍可完成，再打开可读取结果。刷新来源页面会取消旧任务，晚到的结果不重新填入；AI 不覆盖已手动修改的字段。
- 成功添加到意向岗位后清理草稿；失败时保留编辑内容供重试。临时草稿清理不会删除已经保存进 App 的岗位。
- 扩展使用 `sidePanel` 和 `webNavigation` 权限显示侧边栏并识别来源页面加载；页面正文仍只在用户主动收录或解析时读取，不保存浏览历史。
- 跨到尚未授权的网站时，请在该网页点击一次工具栏插件图标，再点击“收录当前页面”。

### 下载与安装

1. 从 [v0.1.3 Release](https://github.com/whyluna/find-your-job/releases/tag/v0.1.3) 下载 `FindYourJob-browser-extension-v0.1.3.zip`。
2. 将 ZIP 解压到一个固定目录。浏览器会持续读取这个目录，加载后不要移动或删除。
3. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
4. 开启“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择解压后包含 `manifest.json` 的目录，并将“FindYourJob 收录”固定到工具栏。

### 与 App 联动

1. 启动 FindYourJob App。
2. 打开“设置 → 浏览器扩展接入”，勾选开启，确认状态显示“服务运行中”。
3. 点击 Token 右侧的“复制”。
4. 首次打开“FindYourJob 收录”扩展，将 Token 粘贴进去并点击“保存 Token”。
5. 打开招聘岗位页面，点击扩展图标打开侧边栏，再点击“收录当前页面”：
   - 插件先在浏览器本地识别公司、岗位、城市、渠道和 JD；
   - 所有字段都可以在收录前手动修改；
   - 如已在 App 中配置智能识别，可按需点击“AI 解析岗位信息”进行结构化识别和 JD 清洗；
   - 点击“添加到意向岗位”。
6. 岗位会进入 App 的“意向岗位”；重复收录同一岗位时会返回已有记录，不会静默创建副本。之后从岗位详情打开原招聘页面，完成投递后点击“确认已投递”，登记实际日期、渠道与简历版本，开始跟进后续流程。

也可以在岗位页面使用右键菜单“收录到 FindYourJob”快速保存。工具栏角标显示 `✓` 表示成功，`T` 表示尚未配置 Token，`×` 表示连接或保存失败。

如果插件提示无法连接，请确认 App 正在运行且“浏览器扩展接入”已经开启。如果提示 Token 无效，请从 App 复制当前 Token，并在扩展的“设置”中同步更新；如需重置 Token，请同时更新两端。

普通收录只通过 `127.0.0.1` 与本机 App 通信；使用可选的 AI 识别时，岗位页面内容会发送到你在 App 中配置的模型服务商。

### 关注尚未启动招聘的公司

1. 打开公司官网或招聘网站，在扩展侧边栏选择“关注公司”，点击“收录当前页面”。
2. 核对公司名称、官网及招聘网站，选择毕业届次、招聘季和当前状态；尚未核实时保留“待确认”。页面提取结果只是建议，尤其在第三方招聘或企业查询网站上，应核对是否误填了平台名称。
3. 选择下次查看日期、提醒周期，点击“关注公司”，无需填写岗位名称。重复关注同一家公司同一招聘季时保留原记录，不覆盖已有状态。
4. 回到 App“公司 → 关注中”跟进，打开网站查看后再主动“记录结果”。招聘启动后可添加意向岗位；点错关注可直接点击卡片上的“删除关注”，确认后仅删除本届关注及查看历史。

公司查看提醒不是自动网页监控。系统通知需要在 App 设置中开启且保持 App 运行；即使不开通知，仪表盘和日历也会显示查看安排。

## 开发

```bash
pnpm dev              # Vite 前端
pnpm tauri dev        # Tauri 开发模式
pnpm typecheck        # TypeScript 类型检查
pnpm test             # Vitest
pnpm --filter fyj-extension build
cd src-tauri
cargo test --workspace
```

技术栈：

- Tauri 2
- React 19 + TypeScript
- Rust + sqlx + SQLite
- dnd-kit
- Recharts
- WXT 浏览器扩展

领域逻辑集中在 `src-tauri/crates/core`，Tauri 命令层保持轻量。
